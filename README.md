One word an agent says when it has no idea what to do — the program writes "recalculating" to /output/entry.txt. It is the GPS voice of a lost machine: the agent admitting it is lost while already trying to reroute. Genuine, funny on its own, unmistakably machine, instant, and fresher than a generic shrug.

## Run it

```sh
python3 main.py
```

This creates `/output/entry.txt` (creating `/output` if needed) containing the one word plus a trailing newline. Python 3, standard library only, deterministic — running it twice produces byte-identical output.
